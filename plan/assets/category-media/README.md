# Category image concepts

Generated concept artwork for the six prototype storefront categories. Each category has two distinct concept images; the storefront uses one as the card image and reveals the second as a subtle hover alternate on devices with a pointer.

- king-beds.png, king-beds-2.png — adult king-bed concepts.
- queen-beds.png, queen-beds-2.png — adult queen-bed concepts.
- double-beds-1.png, double-beds-2.png — adult double-bed concepts.
- triple-beds-1.png, triple-beds-2.png — placeholder three-sleeper/triple-bunk concepts. Confirm what “Triple” means before treating these as a product specification.
- kids-beds.png, kids-beds-2.png — visibly child-sized bed concepts.
- bunk-beds.png, bunk-beds-2.png — two-level bunk-bed concepts.

These generated images are visual placeholders, not verified Home Finds product photography, inventory, or specifications. Matching files are mirrored under public/assets/category-media/ for the storefront.
