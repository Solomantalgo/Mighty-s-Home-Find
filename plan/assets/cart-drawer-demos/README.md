# Cart drawer visual demos

- `demo-1-desktop-side-drawer.png` — compact right-side cart drawer on desktop.
- `demo-2-mobile-bottom-sheet.png` — mobile-first bottom sheet with a sticky checkout action.
- `demo-3-editorial-side-drawer.png` — image-led desktop drawer with a larger bed preview.

These are visual references for the customer-side cart experience. Recommended responsive direction: use the side drawer on desktop and the bottom sheet treatment on mobile. The primary action continues to the full checkout page.
