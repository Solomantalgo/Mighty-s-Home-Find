# Bed configurator sample assets

Prototype image set mirrored from `plan/assets/bed-catalog-variants/`.

There are three designs (`classic-spindle`, `square-grid`, `arched-rail`), five finishes (`matte-black`, `white`, `graphite-grey`, `antique-bronze`, `deep-navy`), and two separate states (`frame`, `dressed`). Use filenames in the form `<design>-<finish>-<state>.webp` and load the matching pair for each selection.

These are generated concept images. Confirm product representation against real Home Finds stock before launch. See `plan/HOMEFINDS-PLAN.md` for the upload-more-designs workflow.
